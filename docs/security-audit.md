# إصلاح فحص حزم npm

طلب المستخدم معالجة نتائج `npm audit` مع استمرار تطوير واجهة الأدمن والوضع الداكن.

## النتيجة

الفحص الكامل قبل التعديل: **15** نتيجة (3 حرجة، 9 عالية، 3 متوسطة). الفحص الكامل بعد التعديل: **0** عبر جميع dependencies، بما فيها أدوات التطوير. هذه نتيجة قاعدة advisories عند التنفيذ، وليست ضمانًا بعدم ظهور ثغرات مستقبلًا.

## التغييرات

- Angular core/common/compiler/forms/platform-browser/router وcompiler-cli إلى **21.2.25**؛ CLI وbuild إلى **21.2.27**. لم يتغير الإصدار الرئيسي Angular 21، ولم يتغير Angular Material/CDK 21.2.14 أو Node.js 24.
- تحديث المكتبات العابرة من خلال حل متوافق لملف القفل؛ منها piscina **5.3.2** وundici **7.29.1**.
- إزالة `xlsx` **0.18.5**؛ لا يوجد إصدار npm مصحح لنتيجتي prototype pollution وReDoS. البديل `write-excel-file` **4.1.1**، مع `fflate` **0.8.3** المصححة.
- تصدير Excel لا يزال ينتج ملف XLSX بأوراق «الحركات المالية»، «مدفوعات الطلاب»، «ربحية الطلاب»، «المصروفات والتكاليف» ونفس ترتيب الأعمدة. النصوص، ومنها أرقام الهواتف وما يبدأ بعلامة =، تبقى خلايا نصية؛ القيم المالية الرقمية تبقى أرقامًا.
- تحميل مكتبة التصدير مؤجل حتى طلب التقرير؛ تظهر حالة الانتظار والأخطاء ويُمنع تكرار التنزيل أثناء التنفيذ.

لم يُستخدم `--force` أو `--legacy-peer-deps`، ولم تُخف نتائج audit أو تُستبعد حزم التطوير. أُعيد حل ملف القفل لتجاوز تعارض تصحيحات Angular القديمة، مع الالتزام بحدود الإصدارات المدعومة والتحقق من التثبيت عبر `npm ci`.

## إعادة التحقق

```bash
npm ci
npm audit
bash scripts/test-admin.sh
npm run build
```

تتضمن الاختبارات فحص ملف XLSX فعليًا بفك ZIP وقراءة XML، وتحقيق أسماء الأوراق والأعمدة والأرقام والصفر والقيم السالبة واتجاه RTL والنصوص غير القابلة للتنفيذ كصيغة.

اختبارات HTTP والواجهة تستخدم استجابات محاكاة. لم تُرسل معاملات مالية حقيقية أثناء التحقق.

التحقق النهائي: تثبيت `npm ci` نجح دون تغيير بصمة ملف القفل؛ `npm audit` الكامل أعاد صفرًا؛ نجح **125 اختبارًا في 25 ملفًا** والبناء الإنتاجي. فحص Chromium لنسخة الإنتاج تحقق من حفظ المظهر، التنقل والفلترة والموبايل، ونزّل ملف Excel فعليًا ثم تحققت أسماء أوراقه العربية الأربع. تظهر تحذيرات حجم CSS غير مانعة لبعض المكونات؛ حدود البناء لم تُرفع.
