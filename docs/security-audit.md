# إصلاح فحص حزم npm

طلب المستخدم معالجة نتائج `npm audit` مع استمرار تطوير واجهة الأدمن والوضع الداكن.

## النتيجة

الفحص الكامل بعد الإصلاح الحالي: **0** عبر جميع dependencies، بما فيها أدوات التطوير. هذه نتيجة قاعدة advisories عند التنفيذ، وليست ضمانًا بعدم ظهور ثغرات مستقبلًا.

## إعادة الفحص بعد تحديث الجدولة

أبلغ المستخدم عن **22** نتيجة (17 متوسطة و5 عالية). الفحص الجديد لملف القفل السابق أعاد **34** نتيجة (2 منخفضة و25 متوسطة و7 عالية)؛ معاينة `npm audit fix` أعادت نفس نتائج المستخدم الـ22. لذلك لم نكتفِ بتشغيل الإصلاح التلقائي أو بفحص تبعيات الإنتاج وحدها.

- تحديث Angular CLI وbuild من **21.2.27** إلى **21.2.29** داخل Angular 21؛ تبعيات التطبيق وAngular core وMaterial لم تتغير.
- التصحيح يجلب `vite` **7.3.7** و`undici` **7.30.1** وMCP SDK **1.32.1**، مع تحديث `body-parser` إلى **2.4.0** و`fast-uri` إلى **3.1.9** عبر ملف القفل.
- بقيت ثغرتا `glob` و`minimatch` في سلسلة `@angular/cli` → `pacote`. توصية audit المتبقية كانت الانتقال إلى Angular CLI 22، بينما المشروع يحافظ على Angular 21.
- أضفنا `overrides` محصورة داخل سلسلة `@angular/cli` للحزمتين معًا: `glob` **^14.0.3** و`minimatch` **^11.0.3**. يجب تحديثهما معًا، لأن glob 13 يستخدم تمثيلًا داخليًا تغيّر في minimatch 11. glob 14 يدعم minimatch 11 مباشرة؛ كلاهما يحتفظ بمسار CommonJS للجهات المستهلكة الحالية. تُراجع هذه الاستثناءات عند تحديث CLI لاحقًا لإزالتها عندما تستخدم السلسلة الأصلية الإصدارات المصححة.

لم يُستخدم `--force` أو `--legacy-peer-deps`، ولم يُعطّل audit أو تُستبعد حزم التطوير. سطر `packages are looking for funding` معلومة تخص تمويل المكتبات، ولا يمثل فشلًا في التثبيت أو ثغرة.

التحقق الحالي: نجح `npm ci` دون تغيير بصمة ملف القفل؛ أعاد `npm audit` الكامل **0**؛ نجح البناء الإنتاجي و**168 اختبارًا في 31 ملفًا** بعد إزالة عرض جدول الأكاديمية بطلب المستخدم. نجحت **6** فحوص توافق للمستهلكين الفعليين لـglob/minimatch (تجهيز الحزم، قواعد التجاهل، الكاش ومسارات TUF). فحص Chromium لنسخة الإنتاج تحقق من إزالة عرض الجدول وطلبه من الرئيسية، صفحات القوائم الثلاث والبحث وتغيير الحجم، حقول الطالب الفارغة، والدارك مود والموبايل باستخدام بيانات محاكاة. تحذيرات حجم CSS غير مانعة؛ حدود البناء لم تتغير.

للحصول على ملف القفل المصحح بعد تنزيل التحديث:

```bash
git pull --ff-only origin main
npm ci
npm audit
```

## الإصلاح السابق

الفحص الكامل قبل الإصلاح السابق: **15** نتيجة (3 حرجة، 9 عالية، 3 متوسطة). بعده أعاد **0** وفق قاعدة advisories وقت تنفيذه.

### التغييرات السابقة

- Angular core/common/compiler/forms/platform-browser/router وcompiler-cli إلى **21.2.25**؛ CLI وbuild إلى **21.2.27**. لم يتغير الإصدار الرئيسي Angular 21، ولم يتغير Angular Material/CDK 21.2.14 أو Node.js 24.
- تحديث المكتبات العابرة من خلال حل متوافق لملف القفل؛ منها piscina **5.3.2** وundici **7.29.1**.
- إزالة `xlsx` **0.18.5**؛ لا يوجد إصدار npm مصحح لنتيجتي prototype pollution وReDoS. البديل `write-excel-file` **4.1.1**، مع `fflate` **0.8.3** المصححة.
- تصدير Excel لا يزال ينتج ملف XLSX بأوراق «الحركات المالية»، «مدفوعات الطلاب»، «ربحية الطلاب»، «المصروفات والتكاليف» ونفس ترتيب الأعمدة. النصوص، ومنها أرقام الهواتف وما يبدأ بعلامة =، تبقى خلايا نصية؛ القيم المالية الرقمية تبقى أرقامًا.
- تحميل مكتبة التصدير مؤجل حتى طلب التقرير؛ تظهر حالة الانتظار والأخطاء ويُمنع تكرار التنزيل أثناء التنفيذ.

لم يُستخدم `--force` أو `--legacy-peer-deps`، ولم تُخف نتائج audit أو تُستبعد حزم التطوير. أُعيد حل ملف القفل لتجاوز تعارض تصحيحات Angular القديمة، مع الالتزام بحدود الإصدارات المدعومة والتحقق من التثبيت عبر `npm ci`.

## إعادة التحقق

```bash
npm ci
npm audit
bash scripts/test-admin.sh
npm run build
```

تتضمن الاختبارات فحص ملف XLSX فعليًا بفك ZIP وقراءة XML، وتحقيق أسماء الأوراق والأعمدة والأرقام والصفر والقيم السالبة واتجاه RTL والنصوص غير القابلة للتنفيذ كصيغة.

اختبارات HTTP والواجهة تستخدم استجابات محاكاة. لم تُرسل معاملات مالية حقيقية أثناء التحقق.

التحقق من الإصلاح السابق: تثبيت `npm ci` نجح دون تغيير بصمة ملف القفل؛ `npm audit` الكامل أعاد صفرًا؛ نجح **125 اختبارًا في 25 ملفًا** والبناء الإنتاجي. فحص Chromium لنسخة الإنتاج تحقق من حفظ المظهر، التنقل والفلترة والموبايل، ونزّل ملف Excel فعليًا ثم تحققت أسماء أوراقه العربية الأربع. تظهر تحذيرات حجم CSS غير مانعة لبعض المكونات؛ حدود البناء لم تُرفع.
