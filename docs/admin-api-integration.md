# ربط عمليات أدمن بسطهالي

التنفيذ يحافظ على Angular 21 وAngular Material وTailwind. استجابة لطلب إصلاح `npm audit` حُدّثت تصحيحات Angular الأمنية داخل الإصدار 21، واستُبدلت مكتبة `xlsx` القديمة بمكتبة `write-excel-file` مع الحفاظ على التقرير العربي. راجع `security-audit.md`. العقود مبنية على نصي Swagger اللذين أرسلهما المستخدم؛ الاختبارات تستخدم HTTP محاكى، ولا تثبت صلاحيات حساب حقيقي أو سلوك الباك إند الفعلي.

| --- | --- |

## حماية البيانات وإعادة المحاولة

- لا تتغير القوائم على أساس نجاح محلي بعد فشل الطلب أو `success: false`.
- مفاتيح الدفع والحضور والحصص التعويضية ترتبط بمحتوى العملية وتبقى ثابتة لإعادة المحاولة. إغلاق الفترة يستخدم `Idempotency-Key` في الهيدر ويحفظه خلال الجلسة.
- إضافة دفعة رصيد الحصص لا توثق مفتاحًا لمنع التكرار؛ عند نتيجة شبكة غير مؤكدة تُحدّث القائمة وتطلب الواجهة مراجعتها قبل إعادة المحاولة الصريحة.
- إذا لم يرجع الخادم قائمة مواد الطالب كاملة، يتطلب التعديل مراجعتها صراحة قبل الحفظ. إسنادات المعلمين والطابع الزمني الأصلي لانتهاء الاشتراك محفوظة.
- أوقات الجداول والمدفوعات المحلية تُحوّل إلى ISO UTC؛ التواريخ دون وقت تُرسل دون تحويل منطقة زمنية.

## حدود التوثيق

- لم يرد GET للمراحل التعليمية، ولا جسم PUT `/education-stages/{id}`؛ لم تُخمن هذه العقود. إنشاء المرحلة يعرض المعرّف عند وروده من الخادم، ويمكن استخدام معرف مرحلة معروف.
- قيم الدور الوظيفي، حالات قرارات تعديلات المستحقات، و`payroll.targetType` ليست مفصلة. تُستخدم المدخلات النصية أو القيمة الواردة من الخادم، دون قائمة قيم مخترعة.
- التوثيق المرسل لا يصف كامل استجابات القوائم أو معاملات صفحاتها؛ القوائم تتعامل مع array أو `data.items`، وتعرض خطأ عند صيغة غير معروفة. لا تفترض الواجهة أن أول صفحة تمثل كل سجلات الخادم.
- لم تُضف endpoints خاصة بالطالب `/me` أو webhooks الدفع إلى لوحة الأدمن. مسارات الكتابة التي لم يرفق لها جسم الطلب، مثل بعض عمليات الأسئلة والمواد والمحادثات، تحتاج توثيقًا كاملًا قبل ربطها. PATCH الملف الأكاديمي للمعلم يكرر قدرة PUT الموجودة، فاحتفظنا بالتعديل الحالي.
- نطاق `api.basstahali.com` محفوظ ضمن مسودة إعدادات البيئة، لكن الوصول الفعلي كان محظورًا. يلزم تفعيل الإعدادات وحساب اختبار لإجراء تحقق فعلي من الصلاحيات والبيانات.

## التحقق

```bash
npm ci
npm run build
bash scripts/test-admin.sh
npm start -- --host 0.0.0.0 --port 4200
```

`test-admin.sh` يشغّل الاختبارات المركزة للعمليات المعدّلة مع ملف إعداد TypeScript مستقل. الجناح الافتراضي القديم يحتوي على اختبارات غير محدثة، منها توقع عنوان `Hello, admin` القديم واختبارات مولّدة دون مزودي الخدمات؛ لم نخف هذه الاختبارات أو نعدّل التطبيق لإرضائها.

فحص المتصفح المحلي في `/workspace/setup/browser/admin-flows.cjs` يتحقق من حمولة POST/PUT للطلاب، تعديل المصروف، تحميل صفحات الإدارة الأربع الجديدة، وعرض الديسكتوب والموبايل باستخدام استجابات محاكاة فقط. الصور في `/workspace/setup/` تعرض بيانات اختبار.

## تجربة الإدارة والمظهر

- التنقل موزّع إلى نظرة عامة، التعليم والطلاب، المالية، وإدارة النظام.
- الشريط العلوي يعرض موقع الصفحة، ويتيح الانتقال السريع بين الصفحات بـ `Ctrl+K` أو `Cmd+K`، مع أسهم لوحة المفاتيح وEnter وEscape.
- المظهر فاتح أو داكن أو حسب إعداد الجهاز، ويحفظ في هذا المتصفح. تغييره متاح قبل الدخول ومن الشريط العلوي وإعدادات الحساب؛ تسجيل الخروج وانتهاء الجلسة لا يمسحانه.
- تحميل HTTP يظهر في مؤشر علوي غير حاجب؛ تبقى تنبيهات انتهاء الجلسة وتأكيدات العمليات متاحة.
- قائمة الطلاب تدعم البحث، تصفية الحالات الواردة من الخادم، الترتيب، وتقسيم السجلات المحمّلة إلى صفحات. لا تفترض هذه الصفحات وجود pagination غير موثق على الخادم.
- نماذج المالية تعرض صاحب العملية والفترة والعملة؛ الرسم البياني لا يجمع تقارير بعملات أو فترات غير متحققة.
- قائمة الموبايل تحصر التركيز أثناء فتحها، وتعيده لزر الفتح عند الإغلاق، مع استعادة التمرير.
